# Dial-altimeter-WiFi
Arduino R4 WiFi controlled dial altimeter. BMP 280 sensor is used to get local air pressure.
The program connects the Arduino to the internet with WiFi and uses an API key to fetch 
local sea-level barometric pressure, allowing altitude to be calculated.
THe connect to WiFi, fetch barometric pressure and parse weather data portions of this
program were written by Github Copilot

This project is documented in the Arduino Project Hub
